# 보물섬 미션투어 앱 — 배포·운영 메모

## 배포 (Vercel)
- 이 폴더를 깃허브 저장소에 올리고 Vercel에 연결하면 끝 (빌드 없음, 정적)
- 주소 예: mission-xxx.vercel.app → 참여권·행사장 QR에 인쇄

## 운영 전 반드시 바꿀 값 (index.html 맨 위 CONFIG, staff.html 맨 아래 상수 — 둘이 같아야 함)
- OTP_SECRET : 입장번호 생성 비밀값 (아무 문자열)
- OTP_SLOT_MIN : 입장번호가 바뀌는 주기(분). 기본 30분. 직전·다음 번호도 통과되므로 경계에서 문제 없음
- STAFF_PIN : 경품수령소 요원 PIN, staff.html 열기 PIN
- S8_ANSWER : 습지 암호 정답 (기본 "물은보물")

## 당일 운영
1. 티켓부스 태블릿/폰에서 `staff.html` 열고 PIN → 큰 숫자 4자리가 지금 입장번호. 참여권 주면서 알려줌
2. 아이는 앱 → 입장번호 → S2 포토존 사진 → S1 그린도서관부터
3. 각 스테이션은 본인이 「완료! 다음 지역 탐험하기」 — 인증은 없음
4. 5곳 완료 → 뽑기권 화면 → 경품수령소 요원이 기록(5곳·시각·사진 썸네일) 보고 PIN 입력 「수령 처리」 → 화면이 「수령 완료」로 고정
5. 폰이 바뀌거나 삭제되면 기록이 사라짐 → 종이 여권 날인으로 대체 판정

## 데이터
- 서버 없음. 진행 상태·사진 썸네일은 그 휴대폰 브라우저(localStorage)에만 저장
- 원본 사진은 「내 폰에 저장」(공유 시트/다운로드)로 갤러리에 저장
